# MPC Poleca i TOP serwery

ACP: MPC Poleca i TOP serwery. Uprawnienie: sls_highlights_manage.

Globalny przełącznik jest nadrzędny wobec ustawień gier. Po wyłączeniu nie można polecać publikacji, wyświetlać wyróżnień ani rozliczać nowych nagród. Ustawienia istniejące pozostają zapisane.

W ustawieniach Metin2/Minecraft administrator wybiera MPC Poleca oraz okresy i tryby TOP. Opcje są widoczne po nadaniu również uprawnienia Highlights. Polecenie konkretnego tematu obsługuje ekran Polecane publikacje albo akcja w temacie. Serwery polecane są ponad numerowaną listą, mają badge MPC Poleca i gwiazdę. Nie konkurują o nagrody okresowe i są chronione przed archiwizacją do wyłączenia polecenia.

TOP dotyczy ostatniego zakończonego dnia, tygodnia, miesiąca lub roku. Wyróżnienie jest widoczne przez następny odpowiadający okres. Przy remisie wyróżniani są wszyscy zwycięzcy. Historia zdarzeń i nagród pozostaje zapisana. Awards rozlicza okres w transakcji, a unikalne oznaczenie okresu chroni przed powtórnym rozliczeniem. Po przerwie zadanie nadrabia okresy partiami.

Publiczny adres: index.php?app=mpcservers&module=highlights&controller=browse. Dawne adresy rankingu przekierowują tutaj. Klasa Rankings jest wewnętrznym kalkulatorem okresów/liczników, a nie modułem publicznego rankingu podbić.
